What Emmental does

One wedge in your menu bar, a few sliders, nothing running in the background. Free, and it stays that way.

For any mouse

  • Acceleration up to 8.0. System Settings stops at 3.0.
  • Scroll speed, set per mouse.
  • Open at login, and your settings come back after sleep and reconnects.

For Logitech mice optional

  • Speed: the sensor's real DPI, 200–8000 on the MX Master 3S, so every movement gets faster, not just flicks.
  • Battery level next to the mouse name.
  • SmartShift: whether the wheel switches to free-spin when you flick it, and how hard a flick it takes.
  • Over Bluetooth, with early support for Bolt and Unifying receivers.

What it doesn't do

  • No background updater, no login, no account.
  • No analytics. It only goes online when you click Check for Updates.
  • About 9 MB of memory, all in.

Why Emmental exists

Logitech's MX mice are great mice. The software around them can feel like a lot: Logi Options+ is a big app for a handful of settings, keeps helpers running in the background, and asks for updates more often than a mouse seems to need.

Over the years it adds up. The Mac this started on had collected more than 2 GB of Logitech software: Options+, the older Logitech Options, and G HUB, each with its own helpers, updaters and drivers. All for one mouse.

Yet the thing most people want is simply a faster pointer. Emmental does that, plus the few extras worth keeping: DPI, SmartShift and battery. It sits in the menu bar, uses about 9 MB, and asks for nothing.

You can build one too

Emmental was built in a couple of days with AI. It worked out Logitech's HID++ protocol by asking the mouse questions one careful, read-only step at a time, before changing anything.

If a gadget you own comes with an app you don't love, you probably don't need the whole suite. Describe the one thing you want, and build that. The source is on GitHub if you want a starting point.

Found a bug? Want a feature?

Emmental is free and built with AI, so it's tested on real hardware but not on every mouse out there. If something's off, or there's a setting you miss, open an issue on GitHub.

Questions

What's the difference between Speed and Acceleration?

Speed is the sensor's DPI: how far the pointer moves for every millimetre the mouse moves, slow or fast. Acceleration only boosts fast movements, so flicks travel further while small, careful movements stay precise. Most people want a higher Speed and a moderate Acceleration.

Why can it go past 3.0 when System Settings can't?

macOS stores acceleration on each mouse and accepts higher values; the System Settings slider just stops at 3.0. Emmental sets the same value, per mouse, up to 8.0.

Does it work with my mouse?

Acceleration and scroll speed work with any external mouse. Speed (DPI), battery and SmartShift need a Logitech mouse that speaks HID++, like the MX Master and MX Anywhere series. Emmental asks the mouse what it supports instead of checking the model, so newer MX mice should work too. It's built and tested on an MX Master 3S over Bluetooth; other models are untested so far.

Why does it want Input Monitoring?

Only for the Logitech features, and only if you turn them on. Changing DPI means talking to the mouse directly, and macOS puts that behind Input Monitoring. The Privacy window in the Dock has the details.

Will my settings survive a restart or sleep?

Yes. Emmental reapplies them when it starts, when the Mac wakes, and when the mouse reconnects. It also checks every few seconds that macOS hasn't quietly put its own values back.

Do I still need Logi Options+?

Not for speed, scrolling, SmartShift or battery. If you rely on custom button mappings or gestures, keep it for now; Emmental doesn't do those.

Why does macOS say it can't verify the developer?

Emmental isn't notarized by Apple yet. Open it once from System Settings › Privacy & Security › Open Anyway, or build it from source; the Install window in the Dock has both.

How heavy is it, really?

About 9 MB of memory with the menu open or closed, no helper processes, and the download is about a megabyte.

Privacy

What Emmental can see

Acceleration and scroll speed use public macOS APIs and need no permissions at all.

Logitech features need Input Monitoring

DPI, battery and SmartShift are settings on the mouse itself. Emmental talks to the mouse with Logitech's HID++ protocol, and macOS only allows that with Input Monitoring permission. Apple's prompt says the app wants to "receive keystrokes from any application", which is the standard wording for any app that reads input devices directly.

Emmental only opens your Logitech mouse's settings channel, and only sends requests to read and change those settings. The Logitech features stay off until you turn them on.

Nothing leaves your Mac

No analytics, no crash reporting, no account. The only time Emmental goes online is when you click Check for Updates in Settings: it reads one small version file from this website, and sends nothing about you or your Mac.

Install — zsh
# 1. Download and unzip, then move Emmental to Applications
$ open Emmental.zip
# 2. First launch: macOS blocks apps that aren't notarized.
# Open System Settings › Privacy & Security, scroll down,
# and click "Open Anyway" next to Emmental. Only once.
# Or build it yourself from source:
$ git clone https://github.com/Huseyinnurbaki/emmental
$ cd emmental && make install
